# LAN743x Netdev CI results (test/MVP)

This repo publishes kselftest results from a Microchip LAN7430 NIC,
in the format consumed by NIPA at https://netdev.bots.linux.dev/.

This is a personal-account test of the publish flow. The production
location (likely `Microchip-Ethernet` or `microchip-ung` on GitHub)
is TBD.

Layout:

- `results.json` — NIPA manifest (rotated monthly).
- `runs/<YYYY-MM>/<branch>.json` — per-run NIPA JSON.
- `logs/<YYYY-MM>/<branch>/` — raw TAP and any auxiliary logs.
- `archive/` — past months' manifests.

The schema is documented at:
https://github.com/linux-netdev/nipa/wiki/Netdev-CI-system

Generated by `tap_to_nipa.py` and `manifest.py` from
`D:\Netdevtest\nipa_reporting\` (Microchip-internal staging).
